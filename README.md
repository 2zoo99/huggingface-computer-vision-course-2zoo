# huggingface-computer-vision-course-2zoo

이번에 만들 것: 이미지가 어떤 클래스인지 예측하는 모델.  
핵심 개념: 처음 보는 개념을 내 말로 3~5줄 설명.  
실습 코드: 셀마다 “왜 필요한지” 짧게 작성.  
직접 바꿔본 것: 이미지 크기·학습률 등을 하나씩 변경.  
결과와 해석: 무엇이 달라졌고, 왜 그랬을지 기록.  
막힌 부분: 오류 메시지, 원인, 해결 방법.  
출처: 강의와 원본 코드 링크.
