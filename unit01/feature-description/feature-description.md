# Feature ?
우리말로 '특징'이라고 부르는 feature는 머신러닝/신경망 모델이 학습하는 input 인스턴스의 속성값을 가리킨다.

데이터의 특징을 만드는 것은 데이터를 효과적으로 구성하고 조작하는것을 말한다.

수치(=number) feature
- 배열/리스트 : 숫자 저장의 간단한 형태. 하나의 행이 데이터 1개, 열은 각 데이터의 특정 feature를 의미한다.
- 텐서(=tensor) : 대규모의 숫자 데이터 세트를 효율적으로 처리할 수 있게 하는 다차원 배열 형태

범주(=categorical) feature
- dict/리스트 : 숫자 레이블에 범주 혹은 범주형 값 할당
- 원핫 인코딩 : 범주형 변수를 이진 벡터(비트)로 변환하는 방식 (범주가 3개라면 001, 010, 100 값 중에 하나가 지정됨)

이미지 feature
- 픽셀 값 : 픽셀 값 행렬 혹은 다차원 배열
- 합성곱 신경망 feature 추출 : 사전 학습 CNN 모델로 feature을 추출하는 방법

## descriptor ?
이미지 속 객체 또는 장면에 대한 정보를 효과적으로 나타내주는 feature 혹은 feature set 이다.

좋은 descriptor를 만드는 몇 가지 aspect = 측면
1. 변환에 대한 불변성 : 회전/이동/크기조정/조명변화 등의 변화에 대해 안정적이어야 한다. 무슨말이냐면, 원래의 데이터와 동일한 설명으로 이해될 수 있어야 한다.

2. 식별성 : 객체에 대한 고유한 정보를 찾아낼 수 있어야 한다. feature 만으로 서로 다른 객체를 혹은 이미지 부분을 구별할 수 있어야 한다.

3. 차원성 : 일반적으로 적절한 크기를 가지는 feature이어야 한다. 지나치게 크지 않으면서도 정보를 충분히 전달할 수 있어야 한다. 차원의 균형을 맞추는 것은 처리 / 저장에 매우 중요하다.

4. 지역성 : descriptor는 이미지에서 지역적인 특징을 식별하는데 자주 사용된다. 특정 영역이나 주요 지점에 초점을 맞추고 이러한 영역의 특성을 설명해서 서로 다른 이미지에서 유사한 부분을 매칭해내고 인식할 수 있어야 한다.
