# Image

참고: [Hugging Face Computer Vision Course — Image](https://huggingface.co/learn/computer-vision-course/unit1/image_and_imaging/image)

## 이미지의 정의

**이미지(Image)** 는 사물, 장면, 사람, 개념 등을 시각적으로 표현한 것이다.

이미지는 다양한 형태로 존재한다.

- 사진
- 그림
- 도면 및 도표
- 스캔 이미지

## 이미지의 수학적 표현

이미지는 위치에 따라 값을 갖는 **함수**로 표현할 수 있다.

예를 들어, 2차원 흑백 이미지는 다음과 같이 나타낸다.

$$
F(x, y)
$$

- **x, y**: 이미지 안의 위치 좌표
- **F(x, y)**: 해당 위치의 밝기를 나타내는 값

컬러 이미지에서는 각 위치에 RGB와 같은 여러 채널의 값이 대응한다.

**명암**은 이미지에서 밝고 어두운 정도 또는 그 차이를 뜻한다.

(x,y) 좌표는 **픽셀**(=화소) 라고 부른다.

**조도**는 함수로 광원에서 나오는 것 혹은 물체에서 반사되는 것을 말한다.

조도 함수는 일반적으로 음수가 아니고, 값이 유한하다.

**3차원 이미지** 즉, 3D 이미지는 F(x,y,z) 함수로 나타낼 수 있다.

3차원 이미지는 '부피'값을 가지며 voxel 이라고 한다. 

3차원 이미지의 예는 아래와 같다.

- 의료 영상
- 자기공명영상
- 현미경 이미지 등

## 이미지 색상

이미지는 채널로 표현하는데 RGB와 같은 색상 표현의 경우 3채널로 표현한다고 말한다.

색상에 대한 **강도**는 0 ~ 255 사이의 범위를 가진다.

## 레이블 포함 이미지

이미지 중에서는 픽셀에 레이블을 지정한 유형의 이미지가 있따.

전경과 배경을 분리한 경우의 이미지가 해당된다.

전경에는 모두 레이블이 1, 배경에는 모두 레이블 0이 지정된다.

이처럼 레이블이 2개 뿐인 경우는, **이진 이미지** 또는 **마스크**라고 부른다.

## 이미지 표현방식

- 행렬 = 2차원 배열
  - 합성곱 신경망 처리
  - 전처리 
- 그래프
  - 노드 = 좌표
  - 간선 = 인접 좌표
 
## 이미지와 비디오의 차이점

비디오는 시간이 포함된 이미지라고 볼 수 있다.

그래서 비디오는 F(x,y,t) 함수로 표현할 수 있다.

**이미지**는 하나의 특정 시점의 정적인 것이라면, **비디오**는 일련의 이미지들이 특정 속도로 연속으로 보여져 움직이는 듯한 착시를 만들어낸 것이라 볼 수 있다.

여기서 속도를 **초당 프레임 수** = **FPS** 라고 한다.

## 이미지와 tabular 데이터

**표 형식 데이터** = tabular에서 차원은 일반적으로 하나의 데이터 포인트를 설명하는 특징 = 컬럼 수로 정의한다.

**시각적 데이터** = 이미지/비디오 에서 차원은 일반적으로 데이터를 설명하는 차원의 수 즉, 함수의 변수 개수와 같다. 

이미지와 tabular 데이터의 또 다른 차이점은 이미지는 **특징**을 생성한다는 것이다.

이미지의 '특징'의 경우는 보통 전처리 과정을 거치면서 만들어지거나, 딥러닝 기법을 통해 학습되면서 만들어진다.

딥러닝 기법을 이용한 경우를 이미지 **특징 추출** 이라고 부르며, 이 과정에서는 다양한 알고리즘이 사용된다.

이에 반해 tabular 데이터는 보통 결측값처리 / 범주형 인코딩 / 수치형 특징값 재조정 등의 전통적인 전처리 알고리즘을 사용하여 이루어진다.
