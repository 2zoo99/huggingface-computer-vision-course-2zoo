# 컴퓨터 비전 작업을 위한 전처리
- 푸리에 변환
- 주성분 분석 = PCA

- 형태학적 연산 : 픽셀 주변 영역 값을 분석해서 동일한 크기의 이미지를 생성하는 연산
- 이미지 개별 조작 연산 : 이미지 거듭제곱, 다른 이미지로 쪼개기
- 수학 집합론 : 이진 이미지를 이해하는 방식에 활용. 픽셀은 보통 전경이 1, 배경이 0으로 표현됨. 이걸 이용해서 합집합과 교집합 연산을 활용해서 픽셀좌표간의 특징 및 관계를 결정. 강도 변환 / 공간 필터링 등도 여기에 포함
- 공간 필터링 : 픽셀 값 주변 픽셀의 값에 따라 변경해서 이미지를 수정하는 기술. 블러처리/선명도 작업에 사용.
- 데이터 증강 : 이미지 분류에 활용되는 CNN의 성능과 일반화 능력을 향상시키는 작업에 중요한 역할을 한다. 이것은 훈련 데이터를 인위적으로 증가시키는 것을 의미한다.

## 데이터 증강
기존 이미지 데이터에 기하학적 변환 / 색 공간 변환 등을 적용해서 원본 데이터의 다양한 형태를 만들어 낸다.

합성 데이터의 경우 심층 신경망 = DNN / 생성적 적대 신경망 = GAN 등의 고급 기술을 활용하여 새롭게 생성한다.

데이터 증강은 이미지 말고도 오디오/비디오/텍스트 등의 데이터 유형이 부족한 상황에서 적용할 수 있다.

이러한 증가된 데이터로 모델의 성능을 향상시키고 과적합을 방지할 수 있고, 데이터 레이블링 / 정제 비용을 절감할 수 있다. 그러나 이럼에도 데이터셋 편향이나 높은 품질 보증 비용 등의 문제는 여전히 존재할 수 있다.
